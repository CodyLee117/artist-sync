# Start here

This is our shared artist workspace. To use it with Claude on your Mac:

1. Accept the Google Drive invite email.
2. In Claude Desktop, install the **artist-sync** plugin (ask whoever sent you this for the zip).
3. Start a Cowork project on an empty folder (for example Documents/Artist Workspace) and type **/setup-artist-sync**
   (or just "set up artist sync"). Choose "join" and paste this folder's link.

Claude will copy everything to your Mac, keep it in sync, and tell you what teammates changed, and why, whenever you open the
project.

Using Obsidian? Open the local folder as a vault, and install the community plugins listed in `knowledge/tools.md` yourself.
Your Obsidian settings stay on your Mac.
