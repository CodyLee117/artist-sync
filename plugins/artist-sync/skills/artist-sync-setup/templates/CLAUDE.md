# Artist Workspace

Our team's shared memory and toolbox. Claude keeps it in sync with Google Drive (the artist-sync skills).

- `knowledge/`: notes, techniques, decisions and references. **Check here first**, and add what we learn. `README.md` is the
  index; `projects/` has one note per project, `procedures/` how we do things, and `people/` work profiles.
- `knowledge/tools.md`: the index of every script, tool and team skill.
- `plugins/animate/`: Adobe Animate JSFL scripts (Commands → Run Command…).
- `plugins/browser/`: the vision browser extension.
- `plugins/scripts/`: other reusable scripts.
- `skills/`: team skills, one folder each, with a `SKILL.md`.
- `templates/`: prompts and workflows that worked.
- `changelog/`: one small note per change (who, why, which files), written by Claude at each sync. Never edit these.
- `.conflicts/`: the losing versions of art files that two people changed at once. The newer version wins, and the older one
  waits here.

Rules:
- Every script, tool and team skill gets an independent review (artist-build-review) before it's shared.
- No generative art. Claude edits and processes images only as the artist directs, and never generates artwork.
- Save reusable work here and list new tools in `knowledge/tools.md`.
- Write paths relative to this folder.
- Never save passwords, keys, tokens, personal settings (`.obsidian/`) or paths to one person's machine.
- Sync after changes.
